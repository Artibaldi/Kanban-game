# Roadmap

Task Bastion grows in stages. Each stage ships rules on the server first, then the client, then a review pass.
Done stages are in the [changelog](CHANGELOG.md).

## Now

- Visual system for the remaining screens: fortress, progress and friendly battles get screenshots in the README.
- Animated wave battle on the walls instead of the text-and-crowns summary.

## Next

- **Production login:** SSO or password with MFA instead of the demo user picker.
- **Live notifications** for confirmations and wave results (today: refresh on action and every 15 s).
- Chests for waves, “Thank you” for helping colleagues, an onboarding chain, a trophy road.
- Release bosses: a release as a special enemy for the whole team.

## Later

- Import tasks from Jira.
- Per-team estimate scale.
- Battles with troop placement and pathing across the map.
- English interface.

## Will not do

- A leaderboard comparing employees, or any use of game data to evaluate work.
- PvP with losses, costs or trophies between colleagues.
