# Рабочий слой по референсу — план этапа 1

**Цель:** перенести в приложение рабочий слой из утверждённого прототипа (доска, проверка, оболочка, главная, прогресс) без изменения серверных правил.

**Основа:** прототип `work.html` (утверждён 2026-10-18), спецификация `docs/superpowers/specs/2026-10-17-coop-backlog-defense-design.md`.

## Ограничения

- Сервер не меняется: все действия идут через существующие `/tasks/{id}/transition`, `/estimate`, `PATCH /tasks/{id}`.
- «Отменить» — обычная обратная операция через тот же API: перемещение возвращается обратным переходом; отмена подтверждения — возврат из «Выполнено» в «На проверке» с причиной, отдельной записью в журнале наград.
- Игровое в рабочих экранах — только золотой чип награды, счётчики золота и энергии и полёт монет; в режиме «Работа» их нет.
- `prefers-reduced-motion`: перелёты, штамп с ударом и FLIP заменяются короткими затуханиями.
- Нет рейтингов и сравнения людей; часы работы не показываются (в системе их нет).
- Шрифты Onest и Rubik, цвета этапов: ready #F2CF5B, in_progress #C24A20, review #1E1E1E, done #2F6B57, backlog #FFF7EC.

## Задачи

1. **Логика (TDD), `web/src/lib/work.ts`:** `initials`, `avatarHue`, `boardStats`, `undoMove`, `dropZoneAccepts`, `stageTone`. Тесты `web/tests/work.test.ts`.
2. **Токены и база:** шрифты в `index.html`, `tokens.css` (палитра, этапы, радиусы, тени, тёмная тема), `base.css` (кнопки-таблетки, стекло, заголовки).
3. **Движение, `web/src/ui/motion.ts`:** `reduced()`, кривые, `flipFrom`, `countUp`, `flyCoins`.
4. **Уведомление-таблетка:** `toast.ts` получает `action` (например «Отменить») и длительность; `Toasts.vue` — тёмная таблетка внизу по центру с полоской времени.
5. **Оболочка `App.vue`:** бренд с командой, навигация-таблетка со сдвигающимся индикатором и счётчиком проверки, игровые счётчики в стиле Clash, переключатель «Работа / Игра», мобильная тёмная панель вкладок.
6. **Карточка `TaskCard.vue`:** заливка цветом этапа, крупные очки, аватар, чип награды; меню «⋯» (`MoveMenu.vue`) вместо кнопки шага — без вложенных интерактивных элементов.
7. **Доска `BoardPage.vue`:** заголовок в две строки, фильтры-чипы, счётчики, перетаскивание указателем (призрак, подсветка колонки, зона «Сдать на проверку»), уведомление с «Отменить», мобильные вкладки этапов.
8. **Окно задачи `TaskDrawer.vue`:** лист цвета этапа, вырастает из карточки (FLIP), крупное число, шкала этапов, метрики; редактирование, оценка, комментарии, история и начисления сохраняются.
9. **Проверка `ReviewPage.vue`:** тёмные карточки, штамп «Подтверждено», монеты в счётчик, «Отменить»; согласование оценок в новом стиле.
10. **Главная и «Прогресс»:** заголовки и плитки счётчиков в новом стиле.
11. **Проверка:** `npm test`, `npm run build`, `go test`, скриншоты десктоп/телефон, оба режима, тёмная тема.
